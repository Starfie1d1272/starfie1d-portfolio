## 为什么做

最开始只是想从 Demo 里多拿一点比赛数据，但很快遇到两个问题：第一，指标算出来以后很难回到具体回合验证；第二，Python 解析器、前端分析和桌面 UI 如果直接绑在一起，格式一改就到处跟着坏。

所以后来把解析、版本化数据格式、分析逻辑和桌面产品分开。Studio 负责导入 .dem、管理比赛、看分析和 2D 回放，RivalHub 也可以复用同一套分析能力。

## 为什么把 Studio 和分析库分开

DAK Studio 用 AGPL-3.0-only；共享的 `@cs2dak/*` 包和 Python 壳用 MIT。许可证边界和代码边界是一致的：其它产品可以直接复用分析能力，但不需要把 Studio 整个搬过去。
